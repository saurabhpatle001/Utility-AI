# ⚡ Utility Sentinel AI

**Smart Utility Operations & Incident Intelligence Platform**

Utility Sentinel AI is a prototype decision-support platform that demonstrates how smart-meter telemetry can be transformed into prioritized utility incidents and actionable operational intelligence.

The system combines:

- Smart-meter telemetry analysis
- Explainable anomaly detection
- Incident severity and risk scoring
- AI-powered incident investigation using Groq
- Utility SOP-based RAG
- Sentence Transformers embeddings
- FAISS vector retrieval
- Streamlit dashboard

---

## 🎯 Problem

Utility operators may receive large amounts of meter telemetry but identifying abnormal conditions and deciding which incidents require attention can be difficult.

Utility Sentinel AI demonstrates a workflow where:

```text
Smart Meter Telemetry
        ↓
Anomaly Detection
        ↓
Incident Detection
        ↓
Severity + Risk Score
        ↓
Incident Evidence
        ↓
AI Investigation
        ↓
Operational Recommendations
